# Convenciones de Git

- Mensaje: `tipo: descripción` (Conventional Commits, sin scope). Tipos: `feat`, `fix`, `docs`, `test`,
  `refactor`, `ci`, `chore`.
- Si el commit implementa UT, las cita: `feat: UT-CU12-MOB-01..03 consulta pública de trámite`.
- Un commit por CU (o por fase en la documentación). Sin línea de co-autoría.
- En PowerShell 5.1 se encadena con `;`, nunca con `&&`.
